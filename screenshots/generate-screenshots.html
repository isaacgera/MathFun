MathFun PWA screenshot generator

One-time helper (not shipped with the app). It renders MathFun's real design tokens and layout into the PWA screenshots the manifest references (used by the Play Store listing and PWABuilder's install UI). Click Download all, then keep the files in this screenshots/ folder. You can replace any of them later with a real device capture using the same filename — nothing else needs to change.

Rendered locally in your browser via canvas — nothing is uploaded. Filenames match the manifest exactly: mobile-home.png, mobile-play.png, wide-home.png.
